# Prolonged Fasting — website

Static website for the Prolonged Fasting app, built with [Astro](https://astro.build).

Served at <https://prolongedfasting.github.io>.

## Develop

```sh
npm install
npm run dev
```

## Deploy

Pushing to `main` triggers a GitHub Action that builds the site and deploys it to
the [`prolongedfasting.github.io`](https://github.com/prolongedfasting/prolongedfasting.github.io) repository.
